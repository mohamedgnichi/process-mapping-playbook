# RACI Matrix

**R = Responsible · A = Accountable · C = Consulted · I = Informed**

| Activity / Decision | Role 1 | Role 2 | Role 3 | Role 4 |
|---|---|---|---|---|
| Process ownership | A | R | C | I |
|  |  |  |  |  |

## Checks
- Each activity should normally have one clear Accountable owner
- Avoid too many Consulted roles
- Confirm escalation ownership for exceptions
